# Lessons

- Para frames de imagem em fundo escuro, evitar `next/image` com `fill` e `bg-background`; usar dimensoes explicitas e fundo claro para nao mostrar blocos pretos durante reload.

- Quando o pedido for alterar textos, preservar JSX, seções, imagens, rotas e layout; trocar apenas strings visíveis, salvo ajuste técnico mínimo necessário para o build.
