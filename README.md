# LorenzPay

Landing page em Next.js 16 com Turbopack para apresentar a infraestrutura de processamento e repasse Pix da LorenzPay.

## Desenvolvimento

```bash
bun install
```

```bash
bun run dev -- -p 3002
```

Abra [http://localhost:3002](http://localhost:3002).

## Conteúdo

- Hero sobre MED 2.0
- Fluxo operacional Pix
- Proteção financeira de eventos elegíveis
- Estrutura de taxa
- Repasse em minutos
- API e operação manual via WhatsApp
- Dashboard operacional
- FAQ
